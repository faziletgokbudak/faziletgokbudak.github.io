Abstract

Measured bidirectional texture functions (BTFs) capture the full appearance of real materials—including parallax, self-shadowing and inter-reflections that analytic SVBRDFs cannot express—but each measurement is billions of values, and every new material requires a new capture. Existing neural BTF representations encode each material as large per-texel latent maps rather than as a point in a shared space from which new materials could be sampled.

We present neural representations of measured BTFs at two operating points. A per-material coordinate network outperforms the recent neural BTF of Xia et al. at matched size (+3.2 dB PSNR) and all prior baselines on every metric. A compact model represents each material by a single 256-dimensional code that conditions a shared decoder; it exceeds the PSNR (+1.2 dB) and colour accuracy of the per-texel latent maps of Rainer et al. with 256 numbers per material instead of millions, and one decoder shared by all materials.

Because each material is a single point in this code space, measured BTFs can be sampled: a class-conditional flow over the codes, trained on the 84 materials enlarged with colourways and hue rotations, generates materials that render and relight as full BTFs.

Overview

The compact model encodes each measured material and its colourways into one 256-float code with a set encoder; a decoder shared by all materials maps the code, texel position and light and view directions to RGB. A class-conditional rectified flow fitted to these codes samples new codes, which the same decoder renders as full BTFs that can be relit. Top right: measured materials reconstructed by the compact model, rendered on objects.
